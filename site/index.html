How it works Features For AI agents Install Why plainkeep

A personal operating system, in a folder of plaintext.

plainkeep keeps your notes, tasks, and journal as ordinary text files in one folder you own — and gives you one command that runs them. Use it yourself, let it run on a schedule, or hand it to an AI assistant. Nothing lives on a server, and nothing leaves your machine without you.

curl -fsSL https://raw.githubusercontent.com/gabros20/plainkeep/main/script/get -o get.sh && sh get.sh

macOS / Linux · needs only git and Python · free, MIT-licensed. The careful type verifies the download first — the README shows how.

Three plain facts.

It's just files.

Everything you keep is a Markdown text file in one folder — we call that folder your vault. You can open any of it in any editor, search it with any tool, and take it anywhere. There is no database and no export button, because there is nothing to export.

your-vault/
├── wiki/       what you know
│   ├── notes/
│   ├── clients/
│   └── projects/
├── tasks/      what you're doing
│   ├── active/
│   └── done/
├── journal/    what happened, day by day
├── inbox/      not filed yet
└── plugins/    commands you add

One command runs it.

You never memorize where things go or how they're formatted. You say what — plainkeep capture "an idea" — and the command does the filing, the naming, and the linking. Every change is recorded with git, so any mistake is one step to undo.

Rules keep it safe.

Before anything runs, a safety check classifies it: reads run freely, writes stay inside your folders, anything risky asks you first, and some things — like sending data anywhere — are simply refused. The same rules apply to you, to the schedule, and to any AI you invite in.

Plaintext is the truth. Git is the undo button. Everything else is rebuildable.

Everyone comes through the same door.

Whether you pick from a menu, type a command, an item on the schedule fires, or an AI assistant acts on your behalf — it all becomes the same plainkeep call, passes the same safety check, and lands in your files the same way. There is no side entrance.

Built for people. Ready for agents.

The same system has two faces. You get menus and short commands designed to be guessable. Software — schedules, scripts, AI assistants — gets precise, machine-readable answers. Both are the same door in different clothes.

for you

Nothing to memorize.

Menus generated from the tool itself, tab-completion that knows your actual notes, and a --dry-run switch that shows what would happen without doing it. If you get a command wrong, the refusal tells you the exact corrected command.

for AI assistants

Same rules as you.

Every command can answer in JSON with a fixed shape, exit codes form a protocol, and a generated contract file describes every command an agent may use. An assistant can act for you — but it can't do anything you couldn't.

$ plainkeep task add "Fix the webhook" --json
{"plainkeep_json":1,"ok":true,"verb":"task",
 "data":{"id":"T-20260816-01","status":"active"}}

Installed in five minutes.

The installer creates your own private vault, wires your machine, and never sends anything anywhere. A guided first-run asks a few questions — including when your day should start and close — with safe defaults everywhere. Needs macOS or Linux, git, and Python 3.10+.

quickstart
$curl -fsSL https://raw.githubusercontent.com/gabros20/plainkeep/main/script/get -o get.sh $shasum -a 256 get.sh # optional: verify against the published hash, read it first $sh get.sh # your private vault + the engine, no sudo $plainkeep setup --wizard # guided first-run: schedule on, heavy extras off $plainkeep ui # point-and-pick from here

Just looking? sh get.sh --demo installs a throwaway vault with example notes into a temp folder — one rm -rf removes it completely. Semantic search, local AI models, and backups are optional layers you can switch on any time with plainkeep setup.
