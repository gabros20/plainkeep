plainkeep

A local-first, agent-agnostic system for your knowledge, tasks, and work. Plaintext is truth, git is the spine, and one plainkeep <verb> surface drives everything — for you, for cron, and for any AI agent.

One system, three commitments

Everything else falls out of these three rules. They're what keep the system yours, portable, and impossible to lock in.

📄 Plaintext is truth

Every note, task, and journal entry is a Markdown file you can read, grep, and edit with anything. Indexes and embeddings are disposable caches rebuilt from the text — never the source of truth.

🌳 Git is the spine

The whole system is one git repo. Every change is a diff, every mistake is revertible, your history is yours. Back it up by pushing to your own GitHub.

⌨️ One command surface

You never poke at files by hand. plainkeep <verb> is the single door — 32 verbs that know where things go and how to keep them safe.

🤖 Agent-agnostic

A model decides what to do; the system guarantees where and how. Any AI agent operates it through the same verbs and the same guardrails you do.

Finding anything — three local stages

All on your machine, no server, no cloud. Keyword search works out of the box; the semantic stages are opt-in and rebuildable from your Markdown.

The index lives in .index/ and is disposable — rm -rf .index && plainkeep index rebuilds it from your notes.

From template to your vault

This repo is a template, not your data. You make your own copy, and one script wires the machine. Your commits go to your GitHub; the template stays a one-way upstream you pull engine fixes from.

  1. Use this template → your own repo, then clone it to ~/plainkeep (the path matters — the safety wall is rooted there).git clone git@github.com:<you>/plainkeep.git ~/plainkeep && cd ~/plainkeep
  2. Run setup — puts plainkeep on your PATH, creates the sibling roots, tracks the template as fetch-only upstream, runs a health check, makes the first commit. It never pushes../script/setup --lean
  3. Make it live — push to your GitHub, then finish the optional layers with the guided first-run: plainkeep setup --wizard (≤5 skippable prompts, safe defaults — search/models/jobs off). Or plainkeep setup --all --yes non-interactively.git push -u origin main plainkeep setup --wizard
    Later: ./script/update pulls only engine files from upstream — your notes are never touched.
